## Исправление ошибки гидратации в `__root.tsx`

**Причина:** Атрибут `data-atm-ext-installed="1.2.28"` добавляется на `<body>` расширением браузера на машине разработчика. Этот атрибут не из кода приложения (поиск подтвердил отсутствие упоминаний в кодовой базе). После SSR расширение модифицирует DOM до гидратации React → React видит несоответствие атрибутов между серверным и клиентским HTML и выдаёт предупреждение "A tree hydrated but some attributes... didn't match".

Это не баг кода, а побочный эффект расширения браузера (явно описан в тексте ошибки React).

**Изменение (единственное):** В файле `apps/web/src/app/routes/__root.tsx`, в компоненте `RootDocument`, добавить `suppressHydrationWarning` к тегам `<html>` и `<body>`:

```tsx
<html lang="en" suppressHydrationWarning>
  <head>
    <HeadContent />
  </head>
  <body suppressHydrationWarning>
    ...
```

**Почему `suppressHydrationWarning`:**
- Это официально рекомендованный React способ для тегов `<html>`/`<body>`, которые часто модифицируются расширениями браузера.
- Подавляет **только** предупреждения о несовпадении атрибутов (не влияет на текстовые узлы/детей), поэтому безопасно — не скроет реальные баги приложения.
- Добавление к обоим тегам (`<html>` и `<body>`) проактивно покрывает другие расширения (менеджеры паролей, проверка грамматики и т.д.), которые обычно пишут атрибуты в оба места.

**Проверка:** После правки перезапустить `npm run dev:web` и убедиться, что предупреждение hydration mismatch больше не появляется в серверной консоли. Поведение приложения не меняется.
