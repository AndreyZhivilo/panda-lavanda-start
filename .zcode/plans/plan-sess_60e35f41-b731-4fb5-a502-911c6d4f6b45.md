### 1. Add a `stripUndefined` helper at the top of `products.repository.ts`

```ts
function stripUndefined<T extends Record<string, unknown>>(obj: T): Partial<T> {
  return Object.fromEntries(
    Object.entries(obj).filter(([, v]) => v !== undefined),
  ) as Partial<T>
}
```

Simple, no dependencies, handles the core concern: removing `undefined` keys so Drizzle `.set()` only updates provided fields.
