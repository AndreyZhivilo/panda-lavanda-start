# План: перенос `packages/db` в отдельный бэкенд `apps/api` (Fastify + Drizzle) — Вариант B

✅ Пользователь одобрил **Вариант B (Фасад + типы domain)**.

## Стратегия

Создать бэкенд-сервис `apps/api` (Fastify + Drizzle ORM), который владеет схемой БД, миграциями и сидингом, и выставляет HTTP-эндпоинты над сущностью products. Веб-репозиторий `DrizzleProductsRepository` заменяется на `HttpProductsRepository`, который обращается к бэкенду по HTTP. Бизнес-логика (капы пагинации, `out-of-stock-last`, фильтры, маппинг snake→camel) целиком переезжает на бэкенд.

**Принятые решения:**
1. **Структура бэкенда — вариант B:** бэкенд импортирует **только типы** (entities, value-objects) из `@panda-lavanda/domain` через `import type`. Репозиторий формально `implements IProductsRepository`, гарантируя контракт. Роуты вызывают репозиторий напрямую (use cases остаются в `packages/application`, выполняются в web).
2. **`packages/db` удаляется** — содержимое (схема, `createDb`, `drizzle.config.ts`, миграции, seed) переезжает в `apps/api`.
3. **`HttpProductsRepository`** экспортируется из **обоих** баррелей `packages/infrastructure` (`index.ts` и `index.client.ts`) — client-safe (только `fetch`).
4. **Сопутствующие задачи:** обновить `docker-compose.yml`, документацию (`architecture.md`, `AGENTS.md`, `README`/`DOCKER.md`), настроить `@fastify/cors`, обеспечить параллельный dev-запуск.
5. **Стек:** `tsx`, `zod`, `@fastify/cors`, Fastify + Drizzle.

## Этап 1. Создать бэкенд `apps/api`

**1.1. `apps/api/package.json`** — `name: @panda-lavanda/api`, private, type module, `imports: { "#/*": "./src/*" }`. Scripts: `dev` (`tsx watch src/server.ts`), `start` (`tsx src/server.ts`), `generate`/`migrate`/`studio` (drizzle-kit), `seed` (`node --env-file-if-exists=.env --import tsx scripts/seed.ts`). Deps: `fastify`, `@fastify/cors`, `drizzle-orm`, `postgres`, `zod`, `@panda-lavanda/domain`, `@panda-lavanda/shared`. DevDeps: `tsx`, `typescript`, `drizzle-kit`, `@types/node`.

**1.2. `apps/api/tsconfig.json`** — extends `../../tsconfig.json`, include `["src", "drizzle.config.ts", "scripts"]`, `types: ["node"]`.

**1.3. Перенос схемы и клиента из `packages/db` (копирование дословно):**
- `apps/api/src/schema/products.ts` ← копия `packages/db/src/schema/products.ts`
- `apps/api/src/schema/index.ts` ← `export * from './products'`
- `apps/api/src/db/client.ts` ← копия `createDb` (импорт `../schema`)
- `apps/api/src/db/index.ts` ← `export * from './client'`
- `apps/api/drizzle.config.ts` ← из `packages/db`, путь `./src/schema/index.ts`, `out: './drizzle'`
- `apps/api/drizzle/` ← перенос миграций (`0000_*.sql`, `0001_*.sql`, `meta/`) целиком
- `apps/api/scripts/seed.ts` ← копия seed, импорты: `createDb` ← `'../src/db/client'`, таблицы ← `'../src/schema/products'`

**1.4. `apps/api/src/env.ts`** — zod-схема: `DATABASE_URL` (min 1), `PORT` (default 4000), `CORS_ORIGIN` (default `http://localhost:3000`), `NODE_ENV`. `export const env = envSchema.parse(process.env)`.

**1.5. `apps/api/src/repositories/products.repository.ts`** — `export class ProductsRepository implements IProductsRepository`, перенос тела `DrizzleProductsRepository` дословно (`create`, `getMany`, `getById`, `delete`, `update`, приватные `buildConditions`/`buildOrderBy`/`mergeProducts`, константы `DEFAULT_PAGE_SIZE`/`MAX_PAGE_SIZE`/`IN_STOCK_EXPR`). Type-only импорты из `@panda-lavanda/domain` и `@panda-lavanda/shared`. Импорты таблиц и `Db` типа — из локальных `../schema/products` и `../db/client`.

**1.6. Fastify-слой:**
- `apps/api/src/plugins/db.ts` — плагин: создаёт `createDb(env.DATABASE_URL)`, инстанцирует `ProductsRepository`, декорирует Fastify-инстанс (`app.productsRepository`).
- `apps/api/src/routes/products.ts` — эндпоинты (zod-валидация): GET `/products` (page, pageSize, search, categoryId, ids csv, sort csv) → `{ items, total }`; GET `/products/:id` → `IProduct` / 404; POST `/products` (CreateProductData) → 201; PATCH `/products/:id` (UpdateProductData) → 200 / 404; DELETE `/products/:id` → 204.
- `apps/api/src/server.ts` — точка входа: создаёт Fastify, регистрирует `@fastify/cors` (origin из `env.CORS_ORIGIN`), плагин БД, роуты, слушает `env.PORT`, graceful shutdown (SIGTERM/SIGINT → закрытие postgres-пула).

**1.7. `apps/api/.env.example`** — `DATABASE_URL`, `PORT=4000`, `CORS_ORIGIN=http://localhost:3000`, `POSTGRES_USER/PASSWORD/DB`.

## Этап 2. Создать `HttpProductsRepository` в `packages/infrastructure`

**2.1. `packages/infrastructure/src/repositories/http-products.repository.ts`** — `export class HttpProductsRepository implements IProductsRepository`, конструктор `(baseUrl: string)`. Реализует 5 методов через `fetch`; бросает `AppError`-подклассы из `@panda-lavanda/domain`: сетевой сбой/некорректный JSON/5xx → `NetworkError`; 404 → `NotFoundError`; прочие 4xx → `ValidationError`. Бэкенд возвращает camelCase `IProduct`, маппинг `as IProduct`. `getMany` собирает querystring (`ids`/`sort` через `join(',')`).

**2.2. Обновить баррели `packages/infrastructure`:**
- `src/index.ts`: заменить экспорт `drizzle-products.repository` → `http-products.repository`.
- `src/index.client.ts`: **добавить** экспорт `http-products.repository` (client-safe), обновить комментарий про Buffer.
- `package.json`: убрать зависимость `@panda-lavanda/db`; убрать `drizzle-orm` (проверить, что больше не нужен).

**3.2. Удалить `apps/web/src/app/composition-root/db.ts`** и реэкспорт `export { db }` из `composition-root/index.ts`. Обновить комментарии.

## Проверка

- Порт `IProductsRepository` (5 методов, plain `Promise<T>`, `throw` на сбое) удовлетворяется `HttpProductsRepository`. Use cases не меняются.
- Server-function `getProducts` не меняется (`sort: [SortOrder.OUT_OF_STOCK_LAST]` пробрасывается через HTTP query).
- CORS разрешит `localhost:3000` → `localhost:4000`.
- Удаление `packages/db` безопасно (потребители: `composition-root/db.ts`, `packages/infrastructure`, `docker-compose.yml` — все обновляются).
- Type-only импорты из `@panda-lavanda/domain` в `apps/api` безопасны (вырезаются компилятором благодаря `verbatimModuleSyntax`).
